# Mosaico firmware

- [`mosaico-idea/`](mosaico-idea/) is the maintained Vibe Mode-compatible Idea firmware.
- [`mosaico-core/`](mosaico-core/) owns its LVGL/Lua runtime, board adapters and UI resources.
- [`mosaico/`](mosaico/) preserves the **discontinued Desktop distribution** and provides the low-level display and ESP-Iris dependencies used by Idea.
- [`mosaico-standalone/`](mosaico-standalone/) preserves the **discontinued full-Flash distribution**.
